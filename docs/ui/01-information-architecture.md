# Arquitectura de información UI

## Locked/discreet

La primera pantalla puede ser:
- calculadora;
- conversor;
- notas simples;
- otra utilidad seleccionada.

La UI no debe tener un botón gigante “ABRIR BÓVEDA SECRETA”.

El mecanismo exacto de entrada debe ser usable por el propietario y documentado internamente/review.

## Unlocked

```text
Home
├─ Todos
├─ Fotos
├─ Videos
├─ Documentos
├─ Carpetas
├─ Favoritos
├─ Recibidos
└─ Transferencias

Contacts
├─ Frecuentes
└─ Agregar por código/QR

Settings
├─ Seguridad
├─ Apariencia
├─ Bloqueo
├─ Identidad
├─ Transferencias
└─ Datos/backup
```
