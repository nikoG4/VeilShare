# Modo discreto

## Objetivo

Reducir aperturas accidentales/curiosidad casual.

## No objetivo

Impersonar una app oficial.

## Modos

### Calculadora
- cálculos básicos reales;
- entrada especial abre unlock flow.

### Conversor
- conversiones reales;
- gesto/acción oculta de UX documentada internamente.

### Notas
- notas señuelo locales separadas de vault, o parte de decoy vault según diseño.

## Android
Opciones pueden modificar icono + label mediante launcher aliases.

## iOS
Opciones principalmente iconos alternativos + surface funcional; nombre de publicación neutro.

## Desktop
Tema/icono/shortcut; no prometer ocultación del proceso.

## Cambio de apariencia

Requiere vault real unlocked.
No permitir desde decoy por defecto si revelar opciones puede delatar.
