# Importación y borrado del original

## Flujo

1. `+`
2. fotos/videos/documentos/cámara
3. picker nativo
4. progreso “Protegiendo…”
5. verificación
6. éxito
7. “¿Eliminar originales?”

## Batch

Para 100 items:
- mostrar total;
- cada item transaccional;
- fallos parciales;
- borrar solo los importados/verificados.

## Mensajes

- `Guardado en la bóveda`
- `No se pudo eliminar el original`
- `El proveedor no permite eliminarlo desde esta app`

Nunca decir “borrado seguro”.
